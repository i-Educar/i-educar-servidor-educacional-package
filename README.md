# Servidor educacional

Motor da vida funcional do servidor municipal: lotação, cessão, centro de custo, licenças, avaliação e hora-atividade × regência.

Composer: `buriti/i-educar-servidor-educacional-package`

## Para que serve

Completa o cadastro de servidor do núcleo com os movimentos funcionais exigidos pela gestão educacional — base para horário, ACT e RH.

## Desenho de funções

| Função | Entrega |
| --- | --- |
| Lotação | Alocação do servidor na rede/escola |
| Cessão | Movimentação entre órgãos/unidades |
| Centro de custo | Vinculação administrativa/financeira |
| Licenças / afastamentos | Registro da situação funcional |
| Avaliação de desempenho | Ciclos e registros associados |
| Hora-atividade × regência | Controle da composição da carga |

## Quem usa

- RH / SME
- Direção
- Servidores

## Integrações

- Núcleo de pessoas/servidores
- RH educacional
- Horário automático
- ACT
